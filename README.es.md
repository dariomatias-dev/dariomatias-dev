### SQL Studio

Aplicación Android para practicar SQL en bases de datos SQLite locales, totalmente sin conexión: catálogo de esquemas listos con datos iniciales, editor con resaltado de sintaxis, consola de resultados e inspector visual de esquema.

**Demuestra:** un producto offline-first con editor de código integrado, ejecución de consultas SQLite y reporte de errores, disposición de área de trabajo configurable e interfaz totalmente localizada en tres idiomas. En beta cerrada.

### Music App

Reproductor de música sin conexión para Android que convierte los archivos de audio del dispositivo en una biblioteca consultable, con listas de reproducción, letras y estadísticas de escucha.

**Demuestra:** una aplicación offline-first con reproducción de audio en segundo plano, base de datos relacional local con Drift, gestión de estado con Riverpod y navegación tipada con go_router.

### MacDocs

Sitio estático de documentación de Matemática Aplicada a la Computación. Un árbol de archivos MDX se convierte en un sitio de estudio navegable y consultable, con renderizado de LaTeX, componentes interactivos y anotaciones por página.

**Demuestra:** una aplicación Next.js orientada a contenido, con generación estática, índice de búsqueda textual con ranking, renderizado matemático con KaTeX, pruebas unitarias con Vitest, pruebas de extremo a extremo con Playwright y axe, y Content Security Policy.
