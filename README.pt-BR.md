### SQL Studio

Aplicativo Android para praticar SQL em bancos SQLite locais, totalmente offline: catálogo de esquemas prontos com dados iniciais, editor com realce de sintaxe, console de resultados e inspetor visual de esquema.

**Demonstra:** um produto offline-first com editor de código embutido, execução de consultas SQLite e reporte de erros, layout de área de trabalho configurável e interface totalmente localizada em três idiomas. Em beta fechado, com site de produto próprio.

### MacDocs

Site estático de documentação de Matemática Aplicada à Computação. Uma árvore de arquivos MDX se transforma em um site de estudo navegável e pesquisável, com renderização de LaTeX, componentes interativos e anotações por página.

**Demonstra:** uma aplicação Next.js orientada a conteúdo, com geração estática, índice de busca textual com ranqueamento, renderização matemática com KaTeX, testes unitários com Vitest, testes ponta a ponta com Playwright e axe, e Content Security Policy.
